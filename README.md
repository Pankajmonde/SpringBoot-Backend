## 📌 About This Repository

This repository contains hands-on code and practice projects covering **Spring Boot Backend Development** — from Spring Core fundamentals to JPA Relationships, REST APIs, Exception Handling and Database Integration.

> Every concept practiced with real code — not just theory! 🚀

---

## 🔑 Key Concepts Covered

### ⚙️ Spring Core
- Tight vs Loose Coupling
- Inversion of Control (IoC)
- Dependency Injection (DI)
- Spring Beans & Bean Lifecycle
- @Component, @Autowired, @Service, @Repository

### 🚀 Spring Boot & REST APIs
- Spring Boot Starters & application.properties
- REST APIs — GET, POST, PUT, DELETE
- @RequestMapping, @PathVariable, @RequestParam, @RequestHeader
- ResponseEntity & HTTP Status Codes
- Exception Handling — @ExceptionHandler, @RestControllerAdvice
- Custom Exceptions & Logging

### 🗄️ Database & ORM
- JDBC — Database connectivity & PreparedStatements
- Transactions — Commit & Rollback
- Hibernate & ORM concepts
- JPA 3 — EntityManager
- JPA Relationships — OneToOne, OneToMany, ManyToMany
- Cascading in JPA
